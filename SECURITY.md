# Security Policy

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Instead, use GitHub Security Advisories for private reporting:

1. Go to the repository page on GitHub.
2. Click the "Security" tab.
3. Click "Report a vulnerability".

If you are unable to use GitHub Security Advisories, do not open a public
issue. Instead, contact the maintainers through a private channel first and
request a private reporting path before sharing any vulnerability details.

## Supported Versions

KOReader Companion is currently in the planning and pre-release stage.
Security fixes will be handled on a best-effort basis.
