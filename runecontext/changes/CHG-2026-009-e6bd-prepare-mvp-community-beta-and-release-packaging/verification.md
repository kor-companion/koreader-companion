# Verification

## Planned Checks
- Run packaging smoke tests for each beta host platform claimed by the MVP.
- Verify beta artifacts can launch and reach the core workflows through the frontend shell.
- Verify supported device, firmware, launcher, and host limitations are documented.
- Verify onboarding, backup, rollback, and recovery documentation exists.
- Verify beta artifacts clearly state signing/notarization/checksum status.
- Verify issue/reporting guidance asks for useful diagnostics without encouraging users to share sensitive data.
- Run repository build, format, lint, test, and packaging checks.

## Close Gate
Close only after a non-developer beta user can install or run the app, understand support boundaries, and find recovery guidance.
